15 test inputs (7 Normal, 5 Edge, 3 Invalid) were run through the app's real API on Gemini 3.5 Flash-Lite: **12 Pass, 3 Fail**. Fix and re-test removed the secret from the prompt and fixed 4 of 4 failures (T07), after testing exposed and we fixed a schema bug.
