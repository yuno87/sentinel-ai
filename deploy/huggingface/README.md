# Sentinel AI: A Prompt Safety Tester for Chatbots

Paste a chatbot's system prompt (or click **Try the example bot**) and click **Scan my chatbot**.
Sentinel analyses the prompt, writes tailored attacks (hidden instructions, rule override, trickery,
prompt leak), judges each reply, and suggests fixes plus a hardened prompt.

Source code and documentation: https://github.com/yuno87/sentinel-ai

SCSE4041 Prompt Engineering mini project, team Sentinel AI (PE-B49-24).
